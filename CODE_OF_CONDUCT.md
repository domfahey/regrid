# Code of conduct

Be respectful, constructive, and welcoming. Critique ideas and code rather than
people. Harassment, discriminatory language, threats, and publishing another
person's private information are not acceptable in project discussions or events.

Maintainers may edit or remove contributions and restrict participation for
violations. Responses should be proportionate and protect affected participants.
Report abuse privately through GitHub's report-abuse controls; do not post private
evidence in public issues. This policy applies to issues, pull requests, reviews,
and other spaces maintained by this project.
